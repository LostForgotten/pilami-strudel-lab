# Documentation de Pilami Strudel Lab

Ce guide correspond à la version **0.39.58**. Les fonctions proposées peuvent varier selon les droits WordPress, le navigateur et le preset chargé.

## Pour commencer

1. [Ton premier visuel en dix minutes](demarrer.md) : essayer sans écrire de code.
2. [Presets et snapshots](presets-et-snapshots.md) : garder une variation, en créer une seconde et passer de l’une à l’autre.
3. [Résolution et fluidité](performance.md) : préparer le rendu pour un écran ou un vidéoprojecteur.
4. [Exporter une page web](export-web.md) : publier une scène, sa miniature et quelques réglages pour le visiteur.

Tu peux utiliser le [laboratoire public](https://pilami.fr/strudel/) sans installer le plugin. Pour ton propre site, commence par [l’installation WordPress](installation.md).

## Quelques mots utiles

| Mot | Dans l’application |
|---|---|
| Strudel | L’espace qui produit la musique |
| Hydra | L’espace qui produit les images |
| Preset | Un script préparé, avec ses paramètres éventuels |
| Contrôleur | Un curseur, bouton ou pad qui fait varier un paramètre |
| Snapshot | Une capture des réglages d’un preset, pas une image ni une vidéo |
| Morphing | Une transition progressive entre des réglages |
| Audio réactif | Un paramètre du visuel suit le son reçu |
| Pack VJ | Une copie du laboratoire Hydra préparée pour jouer hors ligne |
| Page web exportée | Une scène autonome à partager avec un visiteur |
