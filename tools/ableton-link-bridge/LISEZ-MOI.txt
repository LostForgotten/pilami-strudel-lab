Pilami Strudel Lab — Ableton Link (test V1)

Prerequis : Node.js 22+ et Ableton Live (Link active).

1. Lancer 01-installer-windows.cmd (une seule fois).
   Le module natif @ktamas77/abletonlink peut demander des outils de compilation C++ Windows.
2. Dans Ableton Live, activer LINK dans la barre de transport.
3. Lancer 02-demarrer-windows.cmd et laisser la fenetre ouverte.
4. Ouvrir https://pilami.fr/strudel/ dans Firefox puis cliquer Connecter Link.
5. Le BPM et les participants s'affichent. Rien n'est envoye a Live.

Note : la page publique fonctionne normalement sans ce programme.
Si Firefox refuse le WebSocket localhost depuis HTTPS, ouvrir la console F12 et relever l'erreur.
Le bridge ecoute UNIQUEMENT 127.0.0.1:8765 et limite les origines.
La precision du timing/phase dans l'interface n'est PAS garantie pour déclencher des transitions à l'échantillon près.
